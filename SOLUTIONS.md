# SOLUTIONS — решения по проекту sfumato-site

## 2026-08-15 — старт проекта

- **База — копия `~/Downloads/agency-site`, а не новый проект с нуля.**
  Там уже настроена и проверена связка Next.js 16 + Tailwind v4 + Lenis + GSAP
  (плавный скролл, синхронизация ScrollTrigger, Reveal-компонент). Дизайн демо
  выброшен, каркас оставлен.
- **Папка проекта — `~/Desktop/sfumato-site`** (просьба владельца: всё для сайта
  складываем на рабочем столе).
- **Дизайн — Figma-фрейм `V1 / Desktop` (2:2)** файла `bQflGmAfFlCrV1wz7zfpTs`.
  Вёрстка и тексты перенесены из макета через Figma MCP (get_design_context),
  фото/логотипы выгружены оттуда же в `public/images`.
- **Шрифт — NT Somic вместо Onest из макета.** В макете Onest стоял как замена,
  потому что NT Somic нет в Figma. Реальный брендовый шрифт есть локально
  (`~/Desktop/Sfumato/шрифты.zip`) — подключён через `next/font/local` как
  variable-шрифт 100–900.
- **Порт dev-сервера — 3200** (3000 занят qa-research-tool, 3100 — agency-site).
- **Плавные якоря — опция Lenis `anchors: true`**, а не `scroll-behavior: smooth`
  (нативный smooth конфликтует с Lenis — правило №5 из CLAUDE.md).
- **Reveal-анимации — переиспользован готовый `<Reveal>`** (GSAP ScrollTrigger),
  новые ScrollTrigger'ы написаны только в Hero (параллакс фото и вордмарка).
- **Ассеты картинками, не SVG:** вордмарк и знак взяты как PNG-экспорт из Figma
  (там уже правильный тайт-кроп). SVG-исходники логотипа лежат в архивах на
  `~/Desktop/Sfumato`, но их viewBox — целый артборд A4 с огромными полями,
  без обрезки в вёрстке им пользоваться нельзя. Если понадобится ретина-чёткость —
  обрезать viewBox и заменить.
- **hero.jpg** — экспорт из Figma пришёл как JPEG 2000×1115; переименован в `.jpg`.

## 2026-08-15 — моушен-инструменты (подготовка каркаса)

- **Установлены `three` + `@react-three/fiber` + `@react-three/drei`** — 3D/WebGL-слой
  (шейдерные эффекты на фото, объёмные сцены). Подключать только через
  `dynamic(..., { ssr: false })` и лениво (правило №10 CLAUDE.md).
- **GSAP-плагины НЕ докупаем и не доставляем:** с GSAP 3.13 все бывшие платные
  плагины бесплатны и уже лежат в установленном пакете (SplitText, Flip, DrawSVG,
  MorphSVG, ScrambleText, Observer, ScrollTo — проверено в node_modules/gsap).
- **Для Figma ничего в проект не ставим:** Figma MCP уже подключён к Claude Code
  глобально — выгрузка макетов, ассетов и стилей идёт напрямую из файла
  `bQflGmAfFlCrV1wz7zfpTs`. Code Connect для лендинга — избыточен.
