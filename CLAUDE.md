# Проект: сайт агентства sfumàto

Лендинг агентства с сильным моушен-дизайном (уровень awwwards).
Приоритет: плавный скролл, scroll-анимации, микроанимации интерфейса, позже — 3D.

## Как общаться со мной (владелец проекта)

- Отвечай **по-русски**.
- У меня **мало опыта в коде**. Объясняй кратко и простыми словами, что ты изменил и в каком файле.
- Не вываливай длинные листинги кода в чат — вноси правки в файлы, а в ответе пиши итог в 2–4 предложениях.
- Перед крупными изменениями (переписать секцию целиком, сменить библиотеку, поменять структуру папок) — **сначала спроси**.

## Стек — менять только по явной просьбе

| Слой | Что используем |
|------|----------------|
| Фреймворк | Next.js 16, App Router, **JavaScript (не TypeScript)** |
| Стили | Tailwind CSS v4 (конфиг — через `@theme` в `globals.css`, файла `tailwind.config` нет) |
| Плавный скролл | **Lenis** (`lenis/react`) |
| Scroll-анимации | **GSAP + ScrollTrigger** (+ хук `@gsap/react`) |
| Микроанимации UI | **Motion** (бывш. Framer Motion), импорт из `motion/react` |
| 3D (позже) | Three.js + `@react-three/fiber` + `@react-three/drei` |

Не добавляй новые зависимости без спроса. Особенно: не ставь вторую библиотеку плавного скролла,
не ставь AOS / locomotive-scroll / react-scroll-parallax — их роль уже закрыта Lenis + ScrollTrigger.

## Структура

```
src/
  app/
    layout.js        — корневой layout, оборачивает всё в <SmoothScroll>
    page.js          — главная страница: секции и контент
    globals.css      — CSS-переменные (цвета) и токены Tailwind
  components/
    SmoothScroll.js  — Lenis + синхронизация с GSAP ScrollTrigger
    Reveal.js        — универсальное появление блока при скролле
    Hero.js          — первый экран: появление «лесенкой» + параллакс
```

## Правила анимаций — важное

1. **`"use client"`** обязателен в начале любого компонента с GSAP, Lenis или Motion.
2. GSAP пишем **только внутри хука `useGSAP`** со `scope` на ref-контейнер — он сам чистит анимации
   при размонтировании. Не используй голый `useEffect` + `gsap.to` без cleanup.
3. `gsap.registerPlugin(ScrollTrigger)` — на уровне модуля, один раз в файле.
4. **Не трогай синхронизацию Lenis ↔ ScrollTrigger** в `SmoothScroll.js` (`autoRaf={false}`,
   `gsap.ticker.add`, `lenis.on("scroll", ScrollTrigger.update)`). Сломается — анимации поедут вразнобой.
5. **Никогда не ставь `scroll-behavior: smooth`** в CSS и не вызывай `window.scrollTo({behavior:"smooth"})` —
   это конфликтует с Lenis. Для якорей используй `lenis.scrollTo(target)`.
6. **Не используй GSAP ScrollSmoother** — его работу уже выполняет Lenis. Только что-то одно.
7. Анимируй **только `transform` и `opacity`** (x, y, scale, rotate, autoAlpha).
   Не анимируй `width`, `height`, `top`, `left`, `margin` — это дёргает layout и роняет FPS.
8. Для типовых появлений при скролле — **переиспользуй `<Reveal>`**, не пиши новый ScrollTrigger.
   Нужен нестандартный эффект — тогда отдельный компонент.
9. Уважай `prefers-reduced-motion` (правило уже есть в `globals.css`) — не перебивай его `!important`.
10. Тяжёлые эффекты (3D, canvas, видео) подключай через `dynamic(() => import(...), { ssr: false })`
    и не грузи их, если секция не в зоне видимости.

## Стили

- Цвета берём из CSS-переменных в `globals.css`: `--accent`, `--accent-2`, `--muted`, `--background`, `--foreground`.
  В разметке — токены Tailwind: `text-accent`, `bg-accent-2`, `text-muted`.
- Хочешь новый цвет — добавь переменную в `:root` **и** в блок `@theme inline`, потом используй токеном.
- Не пиши инлайновые `style={{...}}`, если то же делается классом Tailwind.
- Не создавай отдельные `.css`-файлы под компоненты.

## Команды

```bash
npm run dev -- -p 3200   # дев-сервер (обычно УЖЕ запущен в соседней вкладке — не запускай второй)
npm run build            # проверка, что всё собирается — прогоняй после заметных правок
npm run lint             # проверка кода
```

Порты 3000 и 3100 заняты другими проектами — используем **3200**.

## Definition of done для задачи

- Правка внесена в файлы, страница в браузере обновилась без ошибок в консоли.
- `npm run build` проходит (если менял что-то заметное).
- Анимация не дёргается и работает на мобильной ширине тоже.
- В ответе — краткий итог: что изменил и в каком файле.
